# Лабораторная работа №2. Кастомная реализация некоторых структур и паттернов

Реализация "с нуля" набора структур, алгоритмов и паттернов без использования стандартных коллекций в Java. Покрытие созданных классов unit-тестами (JUnit 5).

## Запуск

Сборка + прогон всех тестов:

`mvn test`

Сборка без тестов:

`mvn -q -DskipTests package`

## Модули (`lab-2/src/main/java`)

| Пакет             | Ответственность                                                                 |
|-------------------|---------------------------------------------------------------------------------|
| `iterator`        | Интерфейс итератора для обхода ФИО с помощью hasNext() и next(). |
| `list`            | Динамический список на основе массива с поддержкой получения, вставки, замены, удаления элементов и увеличением буфера в ~1.5 раза. |
| `map`  | Ассоциативный массив из узлов ключ-значение с разрешением коллизий с помощью односвязных цепочек. |
| `lazy_singleton`  | Синглтон с ленивой инициализацией через внутренний класс-holder: экземпляр создаётся при первом вызове getInstance(). Этот же способ обеспечивает потокобезопасность.
| `eager_singleton` | Синглтон с жадной инициализацией: экземпляр создаётся один раз и хранится в статическом поле класса, что автоматически потокобезопасно. |
| `stack`           | Стек (LIFO) на массиве с поддержкой добавления, получения и удаления элемента и увеличением буфера в ~1.5 раза. |
| `queue`           | Очередь (FIFO) на кольцевом массиве с поддержкой добавления, получения и удаления элемента и увеличением буфера в ~1.5 раза |
| `sort`            | Быстрая сортивка `QuickSort` in-place по схеме Хоара. Сортировка слиянием `MergeSort`, возвращающая новый отсортированный массив и не изменяет изначальный. |
| `binary_search`   | Итеративный бинарный поиск по отсортированному массиву с защитой от переполнения. |
| `factory`         | Три фигуры, реализующие один интерфейс и создаваемые через общую фабрику с проверкой типа и числа параметров. |

Тесты для каждого из модулей находятся в соответствующих директориях в `lab-2/src/test/java`.
