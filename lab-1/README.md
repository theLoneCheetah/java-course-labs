# Лабораторная работа №1. Банковская система

Банковская система на Java: клиенты, банки, счета трёх типов, транзакции с отменой, уведомления, симуляция времени, консольный интерфейс.

## Запуск

Из корня репозитория:

```bash
mvn -pl lab-1 package
java -cp lab-1/target/classes Main
```

## Модули (`lab-1/src/main/java`)

| Пакет          | Ответственность                                                                 |
|----------------|---------------------------------------------------------------------------------|
| `client`       | Клиент банка и его пошаговое создание (`ClientBuilder`). Статус сомнительного пересчитывается на лету. |
| `account`      | Абстрактный `Account` и три типа: дебетовый, депозит, кредитный. `AccountFactory` создаёт счета. |
| `transaction`  | Command-паттерн: пополнение, снятие, перевод + отмена с защитой от повторной. Журнал `TransactionHistory`. |
| `bank`         | `Bank` (клиенты, счета, условия, лимит для сомнительных) и `CentralBank` (реестр банков, межбанковские переводы, перемотка времени). |
| `notification` | Observer: подписка клиента и рассылка при изменении условий. Каналы: email, sms, push — легко добавить новый. |
| `time`         | `Clock` + `SimulationClock` (перемотка даты без реальных таймеров). |
| `exception`    | Базовое `BankException` и дочерние: недостаточно средств, лимит сомнительного, срок депозита, повторная отмена. |
| `console`      | `ConsoleApp` — меню со всеми операциями; `Main` — точка входа (default package). |

## Реализовано

1. Клиенты: обязательные и опциональные поля, ограничения для сомнительных, снятие ограничений после дозаполнения.
2. Несколько банков со своими условиями (проценты, комиссии, лимиты). Условия можно редактировать.
3. Три типа счетов: дебетовый, депозит, кредитный.
4. Ежедневное начисление процентов и комиссий, выплата раз в месяц.
5. Симуляция времени.
6. Центральный банк: регистрация банков, межбанковские переводы.
7. Уникальные id счетов, пополнение / снятие / перевод.
8. Все операции — транзакции, отмена с защитой от повторной отмены.
9. Уведомления клиентов через Observer, каналы расширяемы.
10. Консольное приложение со всеми операциями.
